coding_rules

编码规则

（根据项目实际技术栈填写，建议包含以下方面）

命名约定

  • 变量/函数：camelCase
  • 组件：PascalCase
  • 常量：UPPER_SNAKE_CASE
  • 文件：kebab-case

错误处理

  • 所有外部调用必须 try-catch
  • 错误信息面向用户，不暴露内部实现
  • 网络请求失败必须有重试或降级策略

安全

  • 用户输入必须验证
  • API Key 等敏感信息不得硬编码
  • 文件路径必须校验，防止路径穿越

性能

  • 避免不必要的重复计算
  • 大列表使用虚拟滚动
  • 异步操作不阻塞 UI

依赖

  • 新增依赖需说明理由
  • 优先使用项目已有的库，避免引入功能重复的包
  • 锁定大版本号
