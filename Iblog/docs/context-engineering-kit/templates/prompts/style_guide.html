代码风格指南

（根据项目实际代码风格调整）

格式化

  • 缩进：2 空格
  • 行宽：不超过 120 字符
  • 尾随逗号：多行时保留

注释

  • 不写 WHAT 注释（代码本身应能说明）
  • 只写 WHY 注释（解释非显而易见的原因）
  • 一行最多，不写多段落注释块

文件组织

  • 一个文件一个主要组件/函数
  • 导入顺序：外部库 → 内部模块 → 类型 → 样式
  • 导出放在文件末尾

组件编写

  • Props 使用 TypeScript interface 定义
  • 状态提升到必要的最低层级
  • 副作用集中在 useEffect 中

类型定义

  • 优先使用 interface 而非 type
  • 避免使用 any，必要时用 unknown
  • 共享类型放在 types/ 目录下
