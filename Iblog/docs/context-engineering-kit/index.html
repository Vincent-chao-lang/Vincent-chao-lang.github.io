Context Engineering Kit

一套面向 AI 辅助编程的项目上下文管理工具包，把项目状态、决策、任务和工作日志外置到文件系统中。

阅读 README 查看完整指南
每日循环
/start 读取项目文档、memory 和 git 状态，恢复工作上下文。
→
编码工作 小步提交，追加任务、决策和关键发现。
→
/wrap 总结当天变更，更新 memory、TASKS 和日志。

Core Ideas

不是写更长的提示词，而是管理可恢复的上下文。

这个工具包把 AI 协作项目中容易丢失的信息拆成稳定文档、实时状态、决策日志和命令模板，让每次新会话都能快速回到正确位置。

01

状态外置化

项目当前状态写入文件，不依赖 AI 的对话记忆。

02

文档驱动

每次会话通过 CLAUDE、TASKS、DECISIONS 和 memory 文件恢复上下文。

03

决策留痕

记录为什么选择某个方案，以及放弃了哪些方案。

04

小步演化

结合 git log 与每日工作日志，让 AI 能回溯项目变化。

Commands

三条命令覆盖初始化、开工和收尾。

安装后命令会复制到目标项目的 .claude/commands/ 目录中。

/init-context

新项目首次使用

分析项目配置和源码，补齐 Context Engineering 目录骨架。

  • 生成 CLAUDE.md 和 ARCHITECTURE.md
  • 创建 TASKS、DECISIONS 与 memory
  • 保留已存在文件，不覆盖
/start

每天开始工作

读取文档、状态和 git 记录，输出当前阶段与下一步建议。

  • 恢复上次工作重点
  • 列出未提交变更
  • 等待进一步指令
/wrap

每天结束工作

根据当天 git 变更和工作区状态，更新短期记忆和日志。

  • 更新 current_state
  • 追加 daily_log
  • 同步任务与 Bug 记录

Templates

模板文件按职责拆分。

安装脚本会把这些模板复制到目标项目中，作为 AI 协作的上下文文件基线。

TASKS.md

进行中、待办、已完成三段式任务追踪。

任务 DECISIONS.md

记录关键技术决策、原因、放弃方案和约束。

决策 memory/current_state.md

每次收尾更新的状态快照，是下次恢复上下文的核心文件。

状态 memory/bugs.md

记录活跃 Bug 与已修复问题，避免重复踩坑。

Bug memory/experiments.md

记录尝试过的方案、结果和结论，减少重复实验。

实验 memory/lessons_learned.md

用现象、根因、解决、教训格式沉淀项目经验。

经验 memory/daily_log.md

按日期记录完成事项、发现和下一步计划。

日志 prompts/coding_rules.md

定义命名、错误处理、安全、性能和依赖规则。

规范 prompts/style_guide.md

定义格式化、注释、文件组织、组件和类型风格。

风格 prompts/review_checklist.md

提交前从功能、质量、安全、性能和兼容性做检查。

Structure

安装后得到一个可持续维护的上下文目录。

your-project/
├── CLAUDE.md
├── TASKS.md
├── DECISIONS.md
├── memory/
│   ├── current_state.md
│   ├── bugs.md
│   ├── experiments.md
│   ├── lessons_learned.md
│   └── daily_log.md
├── prompts/
│   ├── coding_rules.md
│   ├── style_guide.md
│   └── review_checklist.md
└── .claude/commands/
    ├── init-context.md
    ├── start.md
    └── wrap.md
CLAUDE.md 是入口 让 AI 在每次会话开始时获得项目目标、技术栈和关键命令。
memory 是短期记忆 频繁更新当前状态、Bug、实验和每日记录。
prompts 是长期规范 把编码规则、风格和审查清单稳定下来。
Git 是演化历史 小步提交让 AI 可以用 git log 理解项目变化。
