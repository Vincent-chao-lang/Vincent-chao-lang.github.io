你是项目初始化专家。请为当前项目生成 Context Engineering 目录结构，支持 AI 高效协作。

## 执行步骤

### 第一步：分析项目

先了解当前项目：
1. 读取 `package.json`、`Cargo.toml` 或其他项目配置文件（如果存在）
2. 扫描 `src/` 目录了解代码结构
3. 读取已有的 `README.md`、`CLAUDE.md`（如果存在）

### 第二步：生成完整目录结构

在项目根目录创建以下完整结构。**已存在的文件跳过不覆盖，只创建缺失的文件。**

```
project/
├── README.md
├── CLAUDE.md
├── ARCHITECTURE.md
├── TASKS.md
├── DECISIONS.md
├── memory/
│   ├── current_state.md
│   ├── bugs.md
│   ├── experiments.md
│   ├── lessons_learned.md
│   └── daily_log.md
├── prompts/
│   ├── coding_rules.md
│   ├── style_guide.md
│   └── review_checklist.md
└── src/
```

### 第三步：填充每个文件的模板内容

逐一创建所有文件。已存在的文件跳过，在最终总结中列出。

```markdown
每次提交代码前检查：

- [ ] 用户输入是否验证
- [ ] 敏感数据是否加密/脱敏

## 性能
- [ ] 是否有不必要的重复计算
- [ ] 大列表是否虚拟化
- [ ] 异步操作是否有错误处理

## 兼容性
- [ ] 是否影响现有功能
- [ ] 数据结构变更是否向后兼容
```
